# 痛点：
- 整合包自带的“末影流体覆盖板”存在诸多bug且长期无人修复：
  - 在重启服务器后概率丢失持久化状态
  - 挖掘掉附着的gt方块后也会丢失持久化状态
  - 将覆盖板从机器上撬下来后，物品已经进入背包，但机器上仍残留覆盖板外观
  - 偶而无法调整频道
- 只有流体传输覆盖板
- 自带的频道内流体缓存无法被查看、清空，会造成困扰
- 频道数量多了之后，管理起来非常困难


# 最终目的
添加更易用的、能跨维度、即时地、无额外消耗地传输流体、物品、能量的gt覆盖板且兼容GTNH2.9.0整合包

## 添加物品
- 流体折跃覆盖板：只用于传输流体
- 物品折跃覆盖板：只用于传输物品
- 能量折跃覆盖板：只用于传输gt eu
- 聚合折跃覆盖板：能同时传输流体、物品、gt eu
- 折跃频道管理器：手持右键可以管理所有可见频道

其中流体、物品、能量折跃覆盖板均由Luv阶段的组件在组装机+Luv电压合成得到，流体折跃覆盖板还可以直接用末影流体覆盖板在合成台无序合成转换
聚合折跃覆盖板须用三种折跃覆盖板+熔融聚四氟乙烯在组装机+Luv电压合成得到
所有类型的覆盖板均可在配置文件中开启或关闭，关闭后，聚合折跃覆盖板也不再拥有对应类型的传输能力

## 机制
将覆盖板贴到机器上后，蹲下并右键机器对应面，或者在机器GUI里点击覆盖板图标，即可打开频道GUI。

GUI包含左侧边栏作为导航，分别有频道和设置页面。
### 语义
- 频道：类似网络，同频道的所有覆盖板能跨维度和时空互相连接起来。
  - 频道id：每个频道唯一的标识码，修改时必须原子操作，修改过程中断传输并同时修改所有连接到该频道的覆盖板的配置
  - 备注：可随意修改的展示文本
  - 颜色：展示在页面上的颜色，也会应用在覆盖板外观上
  - 传输物体：自动锁定为首个被输入到频道的物体，后续可解锁，解锁后变更为下个输入到频道的物体。物体指minecraft item
- 交互状态：“输入”表示从机器输入到频道；“输出”表示从频道输出到机器；“空”表示不进行动作。只对单一覆盖板生效。
- 权限：默认仅包含私人和公开
- 权限联动：安装了ServerUtilities时联动Team
  - 每个组内的频道共享
  - 有组员、盟友、管理者、陌生人几种身份
  - 为每种身份配置权限：可见、连接（包含调整状态）、修改配置、修改权限、新增频道、删除频道

### 操作方法
以流体页面为例，该页面以列表展示所有可见频道，每列是一个频道，列还展示该频道正传输的item图标以及输入、输出的连接数量。对于拥有修改配置权限的频道，还展示齿轮按钮。
左键点击列时，可以让该覆盖板连接到该频道；再次点击，可以恢复至未连接频道状态。
应用频道后，该频道的列项会置顶。在覆盖板的GUI时，还额外展示一个switch控件，用于切换该覆盖板在该频道的[输入、输出、空]交互状态，默认为 空 状态，且为三按钮形态，以避免误操作。
点击齿轮按钮，可以打开该频道的配置面板，调整频道id、备注、颜色，解锁item，修改权限（必须拥有“修改权限”的权限）。
列表上还有新增频道按钮，点击后弹窗，输入频道id即可创建，权限跟随Team默认。在覆盖板的GUI新增时，可选择创建后直接将该覆盖板连接到该频道。
拥有“删除频道”权限时，在配置面板可以删除频道，必须二次确认。删除后该频道连接的所有覆盖板都会恢复到未连接频道状态。
