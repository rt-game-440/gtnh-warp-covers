# 折跃覆盖板需求文档

基于 GTNH 2.9.0。术语以根目录 `GLOSSARY.md` 为准，关键取舍记录在 `docs/adr/`。

## 1 痛点

- 整合包自带的末影流体覆盖板 bug 多，长期没人修：
  - 服务器重启后有概率丢失持久化状态
  - 挖掉所附着的 GT 方块后，持久化状态也会丢失
  - 把覆盖板从机器上撬下来后，物品已经进了背包，机器上却还残留着覆盖板的外观
  - 偶尔无法调整频道
- 只能传输流体
- 频道内的流体缓存既看不到也清不掉
- 频道多了以后很难管理

## 2 目标

提供更好用的 GT 覆盖板，能跨维度、即时、无额外消耗地传输流体、物品和 GT EU，并兼容 GTNH 2.9.0。上面列出的 bug 都不能再出现。

## 3 物品与合成

| 物品 | 作用 | 合成 |
| --- | --- | --- |
| 流体折跃覆盖板 | 传输流体 | 组装机，LuV 电压，LuV 阶段组件；也可以用末影流体覆盖板在合成台无序合成转换 |
| 物品折跃覆盖板 | 传输物品 | 组装机，LuV 电压，LuV 阶段组件 |
| 能量折跃覆盖板 | 传输 GT EU | 组装机，LuV 电压，LuV 阶段组件 |
| 聚合折跃覆盖板 | 同时传输以上三种 | 组装机，LuV 电压，三种折跃覆盖板加熔融聚四氟乙烯 |
| 折跃频道管理器 | 手持右键，管理所有可见频道 | 组装机，LuV 电压，LuV 阶段组件 |

- 所有配方的具体组件、数量和耗时（包括管理器），在实现阶段参照 GTNH 同类覆盖板的惯例拟一版，再交给需求方确认。
- 用末影流体覆盖板转换得到的是空白的流体折跃覆盖板，旧频率和配置不迁移。
- 带配置的折跃覆盖板单独放进合成台，可以清除配置，得到空白覆盖板。

## 4 核心机制

### 4.1 频道

- 频道分为流体、物品、能量三类，三类之间互相隔离。
- 频道直通，不设缓存：输入端抽出的东西当场送进输出端，频道本身什么都不存（ADR-0001）。
- 每个频道持有一个永不变化的内部 ID，覆盖板只记这个 ID。玩家看到和修改的是频道名，改名不会碰任何覆盖板（ADR-0002）。
- 频道属性：
  - 频道名：同一归属者、同一类型内唯一，可以随时修改
  - 备注：任意展示文本
  - 颜色：显示在列表中，同时应用到覆盖板外观上
  - 分发方式：轮询（默认）或顺序，见 4.3
  - 过滤名单：只有流体和物品频道有，能量频道没有，见 4.3（ADR-0004）
  - 权限：见 4.4

### 4.2 覆盖板与连接端

- 一个流体、物品或能量折跃覆盖板最多连接一个对应类型的频道。
- 聚合折跃覆盖板在三类频道里各连一个，各自算一个连接端，交互状态等配置也各自独立。
- 每个连接端的配置（过滤名单不在其中，它属于频道，见 4.1）：
  - 交互状态：输入（机器 → 频道）、输出（频道 → 机器）、空（不动作）。新连接时默认为空。
  - 输出优先级：一个整数，默认 0
  - 速率：每个运行周期最多搬运多少，可以精确设定数值
  - 运行周期：每隔多少 tick 运行一次

### 4.3 传输规则

**流体与物品**

- 过滤名单属于频道，由该频道的所有输入端和输出端共用：输入端按频道名单从机器里抽取，输出端按频道名单决定接收什么，不需要在两端各配一遍。
- 过滤名单分黑名单和白名单两种。新频道默认是空黑名单，也就是什么都放行；新连接的覆盖板交互状态默认为空，不会因为名单放行就直接开始传输。
- 物品匹配看物品 ID 和损伤值。每个频道的名单有一个「匹配 NBT」开关，默认关闭。不支持矿辞。流体只按流体种类匹配。
- 抽取和灌入的槽位遵循 GT 方块自身的侧面规则，和 GT 传送带、泵覆盖板一致。
- 分发时，输出优先级高的输出端先接收；同一优先级内按频道的分发方式分配：
  - 轮询：在同级输出端之间轮流分配
  - 顺序：按连接到频道的先后顺序依次填满
- 输入端不会把东西送回自己所在方块上的输出端，以免出现抽出来又灌回去的自环。
- 输出端满了，输入端就不再抽取，自然形成背压。

**能量**

- 输入端只从会向外供电的机器（发电机、电池箱、变压器等）抽取 EU。
- 输出端把 EU 直接充进机器的内部储能，不判断电压和电流，不会超压爆炸，也没有损耗（ADR-0003）。

**通用**

- 收发两端都必须处于加载状态。覆盖板不负责加载区块，没加载的一端直接跳过；需要时，玩家自己使用整合包里的区块加载器。
- 速率：配置文件设定全局速率上限（默认不限），玩家可以在单个覆盖板上设一个更低的值，用来定量供料。
- 运行周期：配置文件设定默认周期（20 tick，即新覆盖板的初始值）和最短周期（1 tick）；玩家可以在单个覆盖板上把周期设为不短于最短周期的任意值。

### 4.4 归属与权限

**归属者**

- 创建者在 ServerUtilities 队伍里时，频道归队伍所有；否则归创建者本人。
- 没有安装 ServerUtilities 时，频道只能归个人。
- 玩家入队后，已有的个人频道仍归个人，之后新建的频道才归队伍。
- 队伍解散时，频道转给原队长本人；如果出现同名冲突，就在频道名后面自动加后缀。

**身份**

| 身份 | 判定 |
| --- | --- |
| 管理者 | 队伍的队长和管理员；归属者是个人时，就是本人 |
| 组员 | 队伍成员 |
| 盟友 | 与该队伍结盟的队伍的成员 |
| 陌生人 | 其他所有人 |

**权限项**：可见、连接（含调整交互状态）、修改配置、修改权限、新增频道、删除频道。

**默认权限矩阵**

| 身份 | 可见 | 连接 | 修改配置 | 修改权限 | 新增频道 | 删除频道 |
| --- | --- | --- | --- | --- | --- | --- |
| 管理者 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 组员 | ✓ | ✓ | ✓ |  | ✓ |  |
| 盟友 | ✓ | ✓ |  |  |  |  |
| 陌生人（私人） |  |  |  |  |  |  |
| 陌生人（公开） | ✓ | ✓ |  |  |  |  |

- 「私人」和「公开」只是陌生人身份的两套权限预设。
- 修改分发方式需要「修改配置」权限。

**连接者**

- 每个连接端都会记录它的连接者，也就是最近一次把它连上频道、把带有频道配置的覆盖板贴上机器、或者远程修改过它的玩家。
- 连接、断开、调整交互状态、远程修改连接端时，都要检查操作者是否有该频道的「连接」权限。
- 连接者失去「连接」权限时（例如退队、权限被改、频道从公开改成私人），这个连接端会自动断开。
- 在机器旁边修改覆盖板自身的设置（输出优先级、速率、运行周期）不需要频道权限。
- 过滤名单属于频道，修改它需要该频道的「修改配置」权限，和改名、改色相同；没有这个权限的人只能查看名单。覆盖板和折跃频道管理器都在频道配置面板里按这个权限改名单；连接端自己没有名单，所以管理器不能远程改单个连接端的名单。

**数量上限**：配置文件可以按归属者、按类型设定频道数上限，0 表示不限，默认不限。达到上限后，「新增频道」按钮置灰并提示原因。

### 4.5 持久化与物品化

- 覆盖板的所有配置（连接的频道、交互状态、输出优先级、速率、运行周期）都存放在覆盖板自身，服务器重启和区块卸载后都不能丢。过滤名单随频道一起存档，旧存档里没有名单字段的频道按默认的空黑名单读取。
- 撬下覆盖板，或者挖掉它所在的 GT 方块时，覆盖板以物品形式保留全部配置，再贴上就恢复。物品的提示文本显示配置摘要。
- 贴上带有频道配置的覆盖板时，贴的人成为连接者；如果这个人没有「连接」权限，就只断开频道，其余配置保留。
- 撬下覆盖板后，机器上不能再残留覆盖板的外观。

### 4.6 能贴在哪里

- 流体和物品折跃覆盖板可以贴在任何接受覆盖板的 GT 方块上，包括机器、仓室、管道、箱子。
- 能量折跃覆盖板只能贴在有内部储能的方块上，不能贴在导线上。聚合折跃覆盖板贴在导线上时，能量部分不工作。

## 5 界面

### 5.1 覆盖板 GUI

- 打开方式：蹲下右键机器上贴着覆盖板的那一面，或者在机器 GUI 里点击覆盖板图标。
- 视觉参考见 `docs/concepts/gui-refactor/concept.md`，两者冲突时以本文档为准。
- 界面分左右两栏：左栏从上到下是频道列表、状态栏和玩家背包，右栏是占满整个高度的频道配置面板（见 5.3）。
- 单类型覆盖板只有一种频道；聚合覆盖板在左栏顶部用类型标签切换流体频道、物品频道、能量频道，被服务器禁用的类型显示为灰色。
- 状态栏显示当前状态，以及最近一次断开的原因（未连接、对端未加载、对端已满、被频道名单拦住、该类型已被服务器禁用、连接者失权被断开等）。

### 5.2 频道页

- 以列表展示所有可见频道：
  - 顶部有搜索框，按频道名和备注过滤
  - 按归属者分组：自己或本队伍、盟友、公开
  - 已连接的频道置顶
  - 每一项显示频道名、归属者、颜色、最近传输过的最多 3 种物体的图标，以及输入、输出连接端的数量；鼠标悬停时列出最近传输过的全部种类。这份记录只保存在内存里，重启后清空。
  - 流体和物品频道的每一项还简要显示名单状态，如「黑名单·空（全部放行）」「白名单·3 项」，让玩家在频道页就知道名单存在
- 标签：玩家可以给任何可见频道打私人标签，并按标签筛选。标签只有自己看得到，不需要任何频道权限。
- 左键点击一项只是选中它，不会改变连接；右侧配置面板显示这个频道，在面板顶部操作：覆盖板未连接时是「连接此频道」，已连着别的频道时是「切换到此频道」（直接换连，不二次确认），选中的正是已连接的频道时是「断开」。
- 选中已连接的频道时，右侧面板「连接」分页里的交互状态开关可用，形式为「输入 / 输出 / 空」三个按钮，默认为空，用来防止误操作。
- 列表上有「新增频道」按钮，点击后弹窗输入频道名。新频道的权限采用队伍默认，颜色从 16 色中随机取一种。在覆盖板 GUI 里新增时，可以选择创建后直接连接。

### 5.3 频道配置面板

- 选中任一可见频道时显示在频道列表右侧，没有对应权限的内容只读。
- 面板顶部常驻频道色块、频道名、连接状态和连接操作按钮；下面是文件夹式分页「连接」「过滤名单」「配置」「权限」，一次只显示一页。能量频道没有「过滤名单」分页。
- 「连接」分页是这块覆盖板自己的设置：交互状态、输出优先级、速率、运行周期，数值都可以精确输入；未连接选中频道时整页灰显。
- 「过滤名单」分页见 5.4。
- 「配置」分页可以修改频道名、备注、颜色和分发方式。
- 有「修改权限」权限时，还可以编辑各身份的权限，以及私人/公开预设。
- 有「删除频道」权限时，可以删除频道，需要二次确认。删除后，所有连接端都恢复为未连接。
- 颜色可以从 Minecraft 的 16 种染料色预设中选，也可以输入十六进制 RGB。

### 5.4 过滤名单

- 过滤名单在频道配置面板的「过滤名单」分页里，覆盖板和折跃频道管理器用同一套；管理器的连接端编辑页没有名单区：
  - 可以切换黑名单或白名单，物品名单带「匹配 NBT」开关，支持一键清空
  - 添加区：拿着物品或流体容器点一下，或从 NEI 拖入，把它加入名单，不消耗物品
  - 条数不限，条目以列表显示，可以用鼠标滚轮或上下按钮滚动，每条可单独移除
  - 快捷配置：一次可以把多个候选加入名单。候选只有本机存储中现有的物体，所以只在覆盖板当前连着的频道上可用，管理器没有
  - 修改需要频道的「修改配置」权限；没有该权限的人能看到名单内容，但添加区、快捷、清空和移除都不出现，黑白与 NBT 开关只显示状态
  - 名单拦住了待传输的内容时，覆盖板状态栏提示去频道配置面板里调整名单

### 5.5 折跃频道管理器

- 手持右键打开，界面和覆盖板 GUI 的频道页一样，但没有「连接」操作。
- 可以新增、修改、删除频道，也可以修改权限，都按 4.4 的权限检查。
- 频道配置面板的「连接」分页换成「连接端」分页，列出该频道的所有连接端，包括维度、坐标、机器名、交互状态，以及是否已加载；点一行进入编辑。其余分页和覆盖板一致，按「修改配置」权限编辑频道的名单。
- 对已加载的连接端，有「连接」权限的人可以远程修改它的交互状态、输出优先级、速率和运行周期，也可以把它断开；操作者因此成为新的连接者。未加载的连接端显示为灰色，只能查看，不能修改。

### 5.6 外观与悬停信息

- 单类型覆盖板的中心印记使用频道颜色，上面叠加向内或向外的箭头表示交互状态；未连接时显示为灰色。
- 聚合覆盖板的印记分成三段，分别显示三个频道的颜色。
- 准星对准覆盖板时，通过 WAILA 显示频道名、交互状态、速率和当前状态。
- 不向聊天栏发送状态消息。

## 6 服务器配置项

| 配置项 | 默认值 |
| --- | --- |
| 流体、物品、能量三类各自的开关 | 全部开启 |
| 各类型的全局速率上限 | 不限 |
| 默认运行周期 | 20 tick |
| 最短运行周期 | 1 tick |
| 每个归属者、每种类型的频道数上限 | 0（不限） |

关闭某个类型后：

- 对应的合成配方被移除
- 世界里已经贴着的覆盖板和已有的频道数据都保留，但停止传输，GUI 显示「服务器已禁用」
- 聚合覆盖板的对应部分同样停用
- 重新开启后恢复工作
