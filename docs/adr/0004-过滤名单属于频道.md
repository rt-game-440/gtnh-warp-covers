# 过滤名单属于频道而不是覆盖板

过滤名单由流体和物品频道持有，该频道的所有连接端共用。此前每个覆盖板各持有一份名单，玩家必须在收发两端各配一遍，漏配一端就是「对端过滤」或「被名单过滤」这类难排查的状态；改成频道持有后，只在一处配置，状态也只剩「被频道名单拦住」一种。

后果：

- 新频道默认是空黑名单（放行一切）。以前靠「新覆盖板默认空白名单什么都不传」防止误传，现在由新连接的交互状态默认为空来保证安全。
- 修改名单需要频道的「修改配置」权限，和改名、改色相同；没有该权限的人只能查看。名单不再属于覆盖板自身的设置，不能在机器旁免权限修改。
- 界面上名单在频道配置面板里编辑，覆盖板和折跃频道管理器同一套：管理器也可以按权限修改频道名单，只是不能远程改单个连接端的名单，因为连接端已经没有名单了。面板的入口和分页结构后来由 ADR-0005 改定。
- 名单随频道存档（频道数据的 `filter` 子标签）。旧存档里频道没有这个字段时读成默认空黑名单，旧覆盖板配置里残留的名单字段读取时忽略，不迁移。
- 快捷配置的候选只剩本机存储里的物体；「对端名单」这个来源取消，对端状态 `PEER_FILTERED` 随之删除。
- 能量频道没有名单。

## Considered Options

- 保留覆盖板各自的名单，只加批量同步工具：改动小，但两端不一致的可能性仍在，状态提示也仍要区分本端和对端，被否决。
- 名单同时存在于频道和覆盖板、取交集：规则最灵活，但玩家很难判断到底是哪一层拦住了，被否决。
