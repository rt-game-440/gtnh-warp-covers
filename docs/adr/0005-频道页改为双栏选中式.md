# 频道页改为双栏选中式，点击不再连接

频道页改成左右两栏：左栏是频道列表、状态栏和玩家背包，右栏是占满高度的频道配置面板。左键点频道只是选中它，连接、切换和断开都在右栏顶部明确操作。此前左键直接连接或断开，玩家浏览列表就可能误改连接；配置面板又藏在齿轮后面，名单放在「设置」页时还被误认为是全局设置。

后果：

- 齿轮和「设置」页都去掉。任何可见频道都能点开面板，没有权限的内容只读。
- 右栏分「连接」「过滤名单」「配置」「权限」四个分页。「连接」页是这块覆盖板自己的设置，其余三页是频道共享的，作用范围靠分页区分。能量频道没有「过滤名单」页。
- 已连着别的频道时，顶部按钮是「切换到此频道」，直接换连，不二次确认。按钮文字已经说明后果，交互状态也默认为空，所以不再多弹一次。
- 折跃频道管理器把「连接」页换成「连接端」页，其余和覆盖板一致。
- 玩家背包从界面底部通栏移到左栏下方，右栏因此能占满整个高度。
- 界面尺寸随屏幕的 GUI 空间变化（`core/DualPaneLayout`）：上限 480×320，一般不小于 340×236，屏幕窄于 340 时收缩到 316 宽。打开时定尺寸，界面开着时改窗口大小要重开才生效。

视觉参考见 `docs/concepts/gui-refactor/concept.md`。

## Considered Options

- 保留单栏和弹窗式配置面板，只调整样式：误连和名单难发现的问题都还在，被否决。
- 把本连接端设置放在界面底部通栏（概念图 E）：作用范围最清楚，但高度在 GUI 缩放 4 下很紧，被否决。
- 右栏不分页、所有内容同屏（概念图 A5、F）：不用多点一下，但各区都被压缩，名单区尤其窄，被否决。
