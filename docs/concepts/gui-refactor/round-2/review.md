# 第 2 轮自检

需求方意见：双栏风格不错；点击频道不再连接，而是打开右侧配置面板，在面板里连接。这和 spec §5.2「左键点击一项就连接，再点一次就断开」冲突，等需求方确认后再改 spec。

送审图：A3b（选中未连接的频道）、A4b（选中已连接的频道）。A3、A4 是修正前的版本，保留不送审。

## A3b

- 必须元素：连接此频道、本连接端灰显、名称、备注、颜色、分发方式、过滤名单和权限子标签、黑白名单、匹配 NBT、清空、添加区、条目和滚动、删除频道、状态栏，均已出现。没有「快捷」是对的：§5.4 规定只在当前连着的频道上可用。
- 残留问题（修正一次未解决）：
  - 「主基地水」上的绿点还在，和状态栏「未连接」矛盾。
  - 背包是 10 列 3 行，应为 9 列 4 行。
  - 「全部标签」文字有点糊。
  - 名称、备注输入框是空的，实际应显示频道的值。
- 语义提醒：「熔融钢」属于盟友，默认权限下盟友没有「修改配置」，实际这些控件应为只读。

## A4b

- 必须元素：断开、已连接、输入/输出/空、三项连接端配置、频道配置、名单控件（含快捷）、空名单提示、删除频道、状态栏，均已出现。
- 残留问题：背包同样是 10 列 3 行；「公开」「3 项」有轻微字形失真；颜色色块缺「颜色」文字。

## 未授权事实（两张共同）

- 分发方式画成了下拉框，现有实现是点击切换。
- 分组折叠箭头 spec 未定义。
- 选中蓝框、绿点、「连接后可设置」是这轮新提的表现方式，不是 spec 内容。
- 「连接此频道」在已连接别的频道时是否直接切换，图上没有回答，需要实现前定。
- 频道图标、条目名和数值都是示例。

## 共同提醒

双栏加背包的真实宽度约为现有 196 的 2 倍。需要验证 640×360（缩放 3）和 480×270（缩放 4）能否放下；缩放 4 大概率放不下，可能要单独处理。
