# GUI 重构概念图 Brief

Spec：`docs/需求文档.md`（下文 § 指该文档章节）。两者冲突时以 spec 为准。

## 事实

- 产品类型：Minecraft 1.7.10（GTNH 2.9.0）模组的游戏内 GUI，用于管理跨维度传输频道（§2、§5）。
- 目标用户：GTNH 后期玩家，频道数量多、需要快速找到并配置（§1）。
- 关键界面：
  - 覆盖板 GUI：单类型有「频道」「设置」两页；聚合覆盖板分流体频道、物品频道、能量频道和设置，被禁用的类型显示灰色（§5.1）。
  - 折跃频道管理器：同频道页但无连接操作，配置面板列出所有连接端（§5.5）。
  - 频道配置面板：频道名、备注、颜色、分发方式、过滤名单、权限、删除频道（§5.3）。
- 底部状态栏显示当前状态和最近断开原因（§5.1）。
- 频道页必须有：搜索框、「新增频道」、标签筛选、按归属者分组（自己或本队伍、盟友、公开）、已连接置顶；每项有频道名、归属者、颜色、最多 3 个最近传输图标、输入/输出连接端数量、名单概要（§5.2）。
- 交互状态是「输入 / 输出 / 空」三个按钮（§5.2）。
- 连接端配置：输出优先级、速率、周期（§4.2、§5.4）。
- 过滤名单：黑名单/白名单、匹配 NBT、清空、添加区、可滚动条目、快捷；属于频道，两端共用；默认空黑名单，概要如「黑名单·空（全部放行）」「白名单·3 项」（§4.3、§5.2、§5.4）。
- 权限矩阵：身份为管理者、组员、盟友、陌生人；权限项为可见、连接、修改配置、修改权限、新增频道、删除频道；有私人/公开预设（§4.4）。
- 连接端列表：维度、坐标、机器名、交互状态、是否已加载，未加载的灰色只读（§5.5）。
- 颜色：16 种染料色或十六进制 RGB（§5.3）。

## 约束

- 目标设备：桌面端 Minecraft 窗口，常用 GUI 缩放 3（1920×1080 下约 640×360 GUI 单位）；要兼顾缩放 4（约 480×270）。
- 实现框架：ModularUI2 + GT5-Unofficial（`WarpCoverGui.java`），现有纹理 `GTGuiTextures`；可自绘纹理。
- 视觉基底：像素化字体与斜面控件，要像整合包内的界面。文字要在低分辨率下可读。
- 现状尺寸：覆盖板主面板 196×146，配置面板 300 宽（`WarpCoverGui.java:93-94、130`）。
- 玩家背包：覆盖板和管理器界面都绑定背包（`WarpCoverGui.java:170`、`:276`），§5.4 的添加区要靠它拿起物品，重构后要保留。
- 需求方反馈：放在「设置」页的内容被误认为全局设置；名单藏在齿轮后面不易发现。

## 开放问题

1. 频道列表和频道详情（配置、名单、权限）是同屏并列、逐级进入，还是以本机连接为中心？
2. 聚合覆盖板如何一眼看清三类连接各自的状态？
3. 本连接端配置（交互状态、优先级、速率、周期）与频道共享配置（名单、颜色、权限）如何从视觉上区分，避免误解作用范围？
4. 配置项很多时如何不超屏：弹窗、分页还是抽屉？
5. 沿用 GT 灰色斜面风格，还是换深色终端或工业金属风格？
