# 第 4 轮自检

需求方意见：把 UI 布局重排，更优雅地实现；去掉齿轮（§5.2、§5.3、§5.4 已改）。

这轮比较布局结构，送审 D、E、F，定下结构后再修细节。

## 三张共同的问题

- 频道行本该是最近传输过的物体图标（§5.2），图上画成了人群、锁、铅笔、齿轮等功能图标。这些不作依据，其中的齿轮和已决定的去掉齿轮冲突。
- 背包列数都不对（10 列）；D、E 是 3 行，F 是 4 行。实现时按标准 9×4。
- 频道数量只有 2 到 3 个，长列表和滚动的效果看不出来。

## D 右栏分页

- 必须元素：类型标签、搜索、标签筛选、新增频道、分组、断开、已连接、子标签、名单全部控件、状态栏。「连接」「配置」「权限」子页没画，需要实现前定。
- 其他问题：「熔融钢」的归属者文字是乱码；它和「核电站」都排在「公开」下，属于示例数据问题。

## E 按范围分区

- 必须元素：类型标签、搜索、标签筛选、新增频道、分组、频道配置、连接此频道、名单控件、本连接端通栏、断开、状态。
- 其他问题：名单条目没有图标和移除按钮，缺「快捷」「清空」「删除频道」；列表里「熔融钢」的色块颜色和右栏不一致。
- 这张回答了「选中的频道和已连接的频道不同」时怎么显示。

## F 右栏通高

- 必须元素：类型标签、搜索、标签筛选、新增频道、分组、断开、已连接、本连接端、名单全部控件、频道配置、权限、删除频道、状态栏，全部同屏。
- 其他问题：归属者写成「我」「所有人」，缺最近传输图标；概要「黑名单·空（全部放行）」的小字糊了。
